# AI 教你系統程式 -- 理論與實作

## 書籍簡介

這是一本由 AI 協助撰寫的系統程式（System Programming）入門書籍，涵蓋行程管理、記憶體管理、執行緒與並行、檔案系統、行程間通訊、網路程式設計、組合語言與連結等核心主題。

## 程式碼

本書所有範例程式碼均使用 C 語言編寫，可在 Linux 環境下編譯執行。

```bash
gcc -o example example.c && ./example
```
